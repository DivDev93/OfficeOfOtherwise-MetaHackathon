## Project Description

```text
Office of Otherwise helps speculative-fiction writers, worldbuilders and concept artists explore a what-if as several dated, geographically anchored paths. Compare branches on a globe, inspect an illustrated scene, subject cutout and saved 3D object, then export a scenario brief that separates source-linked baseline context from imagined assumptions, consequences and uncertainty.

The public replay includes four saved stories and requires no credentials or paid generation. Fresh runs retrieve excerpts from fixed public-source registries for Alexandria, Beringia, Green Sahara climate or ancient mechanisms. A baseline must exactly quote a complete retrieved source unit. This preserves source wording; it does not establish historical truth or validate the alternate outcome. Topics are limited to science, technology, culture and geography.
```

## Detailed Use of Meta Products

```text
Meta models perform the core generative work. In current fresh-run code, Muse Spark 1.3 handles prompt and branch topic-policy checks. Muse Wonder proposes geographically anchored scenario branches, reviews them and selects a hero branch. Muse Image generates the hero scene, and SAM 3.1 segments the chosen subject for a cutout. Every Meta request uses the shared metered client and configured spend cap; automated tests use fixtures.

The four historical replay traces attribute policy, proposal and review to Muse Wonder, not Spark. No saved trace establishes Spark narration, and no streamed Spark narration is implemented. The four attached SAM 3D Objects models were generated separately; this public repository validates and attaches supplied GLBs and serves them in replay. Their generation costs are unknown.

The latest recorded fresh text/image/segmentation run completed in 58.666 seconds with US$0.2507162 in estimated Meta ledger cost, one retrieved source and one source timeout. All three saved baselines exactly match complete retrieved source units. This is one observed run, not a reliability guarantee or invoice. The public replay uses cached assets and makes no live model or 3D provider calls.
```

## Why Meta Is Important

```text
Meta's text, image and segmentation models let one creative prompt become a connected set of scenario paths and visual artifacts. Wonder supplies and reviews the alternative paths, Spark checks supported topic boundaries in current fresh runs, Muse Image makes a concrete scene, and SAM 3.1 isolates a subject for inspection. That combination is the project's core workflow rather than an optional assistant beside it. The saved SAM 3D Objects illustrations add an orbitable concept view while remaining clearly separate from fresh generation and from evidence for the imagined outcome.
```
