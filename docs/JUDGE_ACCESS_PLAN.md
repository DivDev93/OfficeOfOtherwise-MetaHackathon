# Judge access and 3D scope

## Local saved replay

Judges clone the public repository and run `npm ci --ignore-scripts` followed by `npm run demo` on Node 22.9.0 or newer. Opening `http://127.0.0.1:3000` displays packaged saved worlds without credentials or model spend. No hosted app is required or authorized; the former Office service and its dedicated image repository have been removed. The submission also includes the public repository and a video release asset.

## Fresh Meta exploration

For local fresh branching, consequences, event scenes, SAM 3.1 cutouts, and optional voice transcription, start `npm run demo` on loopback and enter a key in the page’s **Meta API setup** panel, or configure a startup key in the ignored server-side `.env`. The UI override stays in server memory for that session; it is not persisted by the browser or written to disk. **Clear override** restores the startup configuration, and restarting discards the override. The key is not placed in URLs or logs. Review the configured spend ceilings before making calls. See [the README setup](../README.md#run-it-locally).

## SAM 3D Objects boundary

The four saved root worlds include genuine Meta SAM 3D Objects meshes generated separately through the preexisting private Tattva runner and attached to this repository with provenance. Judges can inspect those saved objects in replay mode. This submission does not offer fresh SAM 3D Objects generation to judges. A Meta Model API key does not provide private Tattva authorization or a SAM 3D endpoint. The optional public live adapter supports TRELLIS only when separately configured; it is not SAM 3D Objects. Do not provision or promise fresh private 3D access as part of judge setup.

The private Tattva/Chronos backend, credentials, and GPU infrastructure remain outside this public repository and submission scope.
