# Three-minute judging demo

The public deployment is replay-only. Use a cached story throughout; do not trigger live generation. The guardrail fixture is simulated and deliberately represents an unavailable classifier, so call that out. The Alexandria replay contains a separately generated SAM 3D Objects model; the model is attached to the saved run and is not generated during playback.
