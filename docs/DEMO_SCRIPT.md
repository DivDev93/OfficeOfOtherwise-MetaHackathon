# Demo recording script — draft

**Do not record as a completed demo until the browser UI, replay assets and 3D viewer have been verified.** The Alexandria / orrery replay is a provisional 2D preview; the separate guardrail replay is a simulated unavailable-classifier case. Replays are not live generation. If no verified 3D model exists, show the image and cutout, state that 3D is in development, and do not imply a model was generated.

| Time | Screen and narration |
| --- | --- |
| 0:00–0:20 | Open the demo. Type **“What if the Library of Alexandria never burned?”** “Office of Otherwise turns a point of divergence into a set of places and possible futures.” Start the run or select the verified Alexandria replay if live is slow. Show the globe if working. |
| 0:20–1:20 | Show the branches and their locations as they appear; distinguish replay from streamed live results. “Muse Wonder proposes and reviews the branches; the provenance strip shows the recorded model, timing and estimated cost.” For the five-second guardrail moment, select the **simulated guardrail** replay: it uses the safe prompt “What if an ancient library survived?” and deliberately simulates an unavailable classifier to show the fail-closed response. Say that it is simulated, then use the retry suggestion to open the Alexandria preview. |
| 1:20–2:20 | Select the hero. “Muse Image renders the scene and SAM 3.1 isolates the subject.” Show the image and cutout. If a verified model is available, orbit it and say “Tattva TRELLIS runs on existing Chronos infrastructure.” Otherwise show the cutout and explain that the 3D handoff is being developed. |
| 2:20–3:00 | Show the public repository and architecture. “The event work includes the policy, branch agent, metered Meta client, image and segmentation harness, and any demo components verified by recording time. Chronos is existing infrastructure; its globe, accounts, credits and 3D pipeline predate the event. The intended business is an exploration product supported by credits.” Show the verified commit range from the submission draft, updated to the final commit. |

**Recording checklist:** confirm actual UI labels, replay provenance, asset quality, model loading, public link and final commit before recording. The guardrail fixture is simulated; it is not a recorded Muse verdict. The provisional orrery mask omits Saturn and some thin parts.
